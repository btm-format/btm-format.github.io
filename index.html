BTMA — Beat-Tracking Media (Animation) demo

A demonstration of the v0.2 BTMA file format: GIFs that retempo themselves in real time to match accompanying music. Pick a track below; the detected BPM drives the renderers underneath.

Music

Click play on any track. Playing one stops the others. Nothing autoplays. Each track's BPM slider scales playback like DJ software — pitch stays constant as tempo changes. The BTMA renderers below sync to the active track's effective BPM.

    Instructions:

    1. Pick a .gif file from your computer.
    2. Use the dropdown to declare how many beats long the loop is.
    3. Press a play button above to start music. Your GIF will sync to the active track's tempo.

    Limits: max file size 1 MB (Twitch's animated-emote cap). The file is rendered at 28×28, 56×56, and 112×112 — the three Twitch emote sizes. Non-square GIFs are letterboxed with black bars; resolution is otherwise not validated.
